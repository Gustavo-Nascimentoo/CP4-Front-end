# CP4-Front-end

Projeto de front-end desenvolvido como atividade acadêmica para criar uma landing page responsiva com destaque para imagens de paisagens, layout em grid e experiência visual moderna.

## 📌 Sobre o projeto

Este projeto consiste em uma página inicial estilo landing page inspirada em destinos de praia e paisagens naturais. A interface utiliza imagens em sequência, composição com grid, efeitos de hover e responsividade para diferentes tamanhos de tela.

A página foi construída com HTML e CSS puros, com foco em:

- layout responsivo;
- apresentação visual de imagens em destaque;
- uso de CSS Grid para organização dos elementos;
- navegação simples e estética limpa.

## 🖼️ Funcionalidades

- Banner principal com múltiplas imagens em destaque;
- Seção de galerias com imagens de paisagens marinhas;
- Efeito de zoom suave ao passar o mouse;
- Botão de chamada para ação ("Saiba Mais");
- Design adaptável para desktop, tablet e mobile;
- Estrutura leve e sem dependências externas.
